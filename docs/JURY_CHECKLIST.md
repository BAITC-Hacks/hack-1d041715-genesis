# Jury verification checklist

A lightweight checklist for the final hackathon review. It does not affect application runtime.

- [x] Project installs from the README instructions
- [x] Demo mode runs without personal accounts
- [x] Offline end-to-end demo flow is explicitly marked as fixture/mock
- [x] Speaker-separated demo transcript is visible
- [x] Action items include task, assignee, deadline, and unknown values
- [x] Meeting summary is generated in the demo flow
- [x] DOCX protocol can be exported and has been visually checked
- [x] All 20 tests pass without paid API calls
- [x] `.env`, API secrets, venv, caches, and generated files are not committed
- [x] README and CONTEXT.md match the implemented functionality
- [ ] Real RU/KZ and mixed audio quality is validated on a representative corpus

> API mode uses an external cloud provider and is not a closed-loop deployment.
