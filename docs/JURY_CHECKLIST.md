# Jury verification checklist

A lightweight checklist for the final hackathon review. It does not affect application runtime.

- [ ] Project installs from the README instructions
- [ ] Demo mode runs without personal accounts
- [ ] Audio processing flow is demonstrated
- [ ] Speaker-separated transcript is visible
- [ ] Action items include task, assignee, and deadline
- [ ] Meeting summary is generated
- [ ] DOCX protocol can be exported
- [ ] Tests pass
- [ ] `.env` and API secrets are not committed
- [ ] README and CONTEXT.md match the implemented functionality

> Keep this checklist aligned with the actual implementation; do not mark an item complete until it has been verified.
