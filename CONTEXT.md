# Контекст проекта — система автопротоколирования совещаний

## Назначение

Сервис преобразует аудиозаписи совещаний на русском, казахском и смешанной речи
в структурированный протокол. Первый модуль отвечает только за транскрипцию.

## Ограничения

- Реальная транскрипция и RU/KZ mixed пока не проверены на предоставленном аудио.
- API-режим передаёт аудио во внешний облачный сервис и не является закрытым контуром.
- Причина отказа конкретного пользовательского аудио определяется по серверному логу;
  проверочные WAV-запросы к обоим OpenAI audio providers проходят успешно.
- Demo-режим использует явно обозначенные fixture/mock-данные.
- Контекстное имя назначается только при сильном сигнале; иначе остаётся `SPEAKER_XX`.
- Облачный provider заменяем через конфигурацию; промышленный on-premise provider пока не реализован.

## Проверено

- Чистая установка в новой `.venv` по `requirements.txt`.
- Импорт установленного пакета без ручного `PYTHONPATH`.
- 20 автоматических тестов без платных API-вызовов.
- HTTP demo-flow: стартовая страница, обработка, результат и скачивание DOCX.
- DOCX структурно проверен и визуально просмотрен после рендера.
- Demo-mode работает без API-ключа и сети.
